# Commit demo v2

Placeholder lines for the short-message fixture.

A few more lines were appended so the second fixture commit shows a
changed hunk rather than a pure addition, which is the interesting case
for a diff viewer.

Modified again in the third fixture commit so this file carries a second
changed hunk on top of the earlier one, which is where a diff viewer's
hunk headers and context lines usually get the spacing wrong. The extra
lines are deliberately dull: their only job is to make the hunk big
enough to be worth looking at next to the two brand new files beside it.
